# S. Karvannan — Portfolio

Premium neumorphic photography/videography/cinematography portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

All content is sourced from the provided resume. Portfolio imagery uses placeholders — replace `src/components/Portfolio.jsx` gradient blocks and `src/components/About.jsx` portrait block with real photographs when available.
